# ClipDown

一个 macOS 剪贴板历史工具。按 `⌘D`,面板从屏幕底部升起,覆盖在 Dock 之上;
选一条历史记录,直接粘贴回你正在用的应用。

它还有一个重点功能:**复制了 Markdown(比如 ChatGPT 的回答),按 `⌘⇧V` 就能粘贴成排好版的富文本**,
`⌘V` 则依然粘贴 Markdown 原文。

- 系统要求:macOS 14 或更高
- 完全本地运行,不联网,不上传任何内容

---

## 安装

1. 打开 [Releases 页面](https://github.com/xCnccw/ClipDown/releases),下载最新的 `ClipDown-x.y.z.zip`。
2. 解压,把 `ClipDown.app` 拖进“应用程序”文件夹。
3. 第一次打开(见下一节),然后按提示授予“辅助功能”权限(见再下一节)。

### 第一次打开:提示“无法验证开发者”怎么办

ClipDown 没有经过 Apple 的开发者签名和公证,所以别人下载后**第一次打开会提示“无法验证开发者”**。
这是正常的,任选一种方式放行即可,只需要做一次:

**方式一:右键打开**

1. 在“应用程序”里找到 `ClipDown.app`。
2. **右键**(或按住 `Control` 点击)它,选择“**打开**”。
3. 在弹出的对话框里再点一次“**打开**”。

**方式二:终端命令**

```bash
xattr -dr com.apple.quarantine /Applications/ClipDown.app
```

(如果你没有把它放进“应用程序”,把路径换成 `ClipDown.app` 实际所在的位置。)

> 如果在 macOS 15 及以上版本里右键“打开”仍然被拦截:到“系统设置 → 隐私与安全性”,
> 在页面下方找到关于 ClipDown 的提示,点“仍要打开”。

### 授予“辅助功能”权限

选中一条记录后,ClipDown 需要替你按下 `⌘V` 才能把内容粘贴进当前应用,这要求“辅助功能”权限:

1. 第一次粘贴时系统会弹出提示,点“打开系统设置”。
2. 在“隐私与安全性 → 辅助功能”里,把 **ClipDown** 的开关打开。

没有这个权限,历史记录和面板仍然能用,但无法自动粘贴(内容会被放进剪贴板,你可以手动 `⌘V`)。

> 重新下载、替换了新版本的 `ClipDown.app` 之后,系统有时会让这个权限失效。
> 如果粘贴没反应了,在“辅助功能”列表里把 ClipDown 先删掉再重新添加即可。

## 使用

ClipDown 常驻在菜单栏(剪贴板图标),没有 Dock 图标。复制的内容会自动记录下来。

### 基本操作

| 操作 | 按键 |
|---|---|
| 呼出 / 收起面板 | `⌘D`(可在设置里修改) |
| 收起面板 | `Esc`,或点击面板外部 |
| 左右切换选中的记录 | `←` `→` |
| 粘贴选中的记录(原文) | `↩` |
| 以纯文本粘贴 | `⇧↩`(可在设置里修改) |
| 快速粘贴第 N 条 | `⌘1` … `⌘9` |
| 只复制,不粘贴 | `⌘C` |
| 预览 | `Space` |
| 删除选中的记录 | `Delete` |
| 搜索 | 直接输入文字,或按 `⌘F` |
| 加入固定板 | `⌘P` |
| 在历史和各个固定板之间切换 | `Tab` |

用鼠标也可以:单击卡片选中,**双击**卡片粘贴,右键卡片会出现菜单(粘贴、纯文本粘贴、转为富文本粘贴、仅复制、添加到固定板、删除)。

### 把 Markdown 粘贴成富文本

这是 ClipDown 的 Markdown 插件。流程很简单:

1. 复制一段 Markdown 文本(例如 ChatGPT、文档里的回答)。
2. 切到要粘贴的应用,按 **`⌘⇧V`**。
3. 粘贴出来的是排好版的富文本:标题、加粗、列表、表格、引用、代码块、分隔线等。
   粘贴完成后,剪贴板会自动恢复成原来的 Markdown。

| 想要的效果 | 按键 |
|---|---|
| 粘贴 Markdown 原文 | `⌘V`(系统自带,ClipDown 不改动) |
| 粘贴成富文本 | `⌘⇧V`(全局,任意应用里都有效) |
| 面板里选中一条,粘贴成富文本 | `⌘⇧V`,或右键卡片 →“转为富文本粘贴” |

说明:

- `⌘⇧V` 是全局快捷键,会覆盖某些应用自带的同名功能
  (例如“粘贴为纯文本”“粘贴并匹配样式”)。如果有冲突,在设置里换一个键位即可。
- 有些应用本身不支持富文本(例如终端、纯文本编辑器),在里面粘贴出来的还是普通文本。
- 剪贴板里不是文本(比如图片)时,`⌘⇧V` 等同于普通的 `⌘V`。

### 固定板

固定板用来长期保存常用内容,不会被自动清理。

- 点击顶部标签栏的 **+** 新建,直接输入名字、选一个颜色。
- 右键标签可以重命名、换颜色或删除。
- 选中记录后按 `⌘P`,或右键卡片 →“添加到固定板”,可以把它放进固定板。

### 设置

点击菜单栏图标 →“设置…”(`⌘,`):

- **快捷键**:呼出面板、纯文本粘贴、Markdown 转富文本粘贴,都可以自定义。
  点一下按钮,再按你想要的组合键;按 `Esc` 取消。“恢复默认”可还原。
- **历史保留时间**:1 天 / 1 周 / 1 个月(默认)/ 3 个月 / 6 个月 / 1 年 / 永久。
  超过时间的记录会自动删除,固定板里的内容不会被删。

### 隐私

- 所有数据只保存在你自己的电脑上:`~/Library/Application Support/ClipDown/`。
- 不联网,没有任何统计或上传。
- 密码管理器等标记为“机密”“临时”的剪贴板内容不会被记录。
- 想清空历史:菜单栏图标 →“清空历史(保留固定项)”(固定板里的内容会保留);想全部清除,删掉上面那个文件夹即可。

## 从源码构建

需要 Xcode 命令行工具和 Swift 5.9 以上。

```bash
git clone https://github.com/xCnccw/ClipDown.git
cd ClipDown

# 直接运行
swift run -c release

# 或者打成 ClipDown.app(输出在 dist/)
./scripts/build-app.sh 1.0.0

# 同时支持 Apple 芯片和 Intel
UNIVERSAL=1 ./scripts/build-app.sh 1.0.0
```

运行测试:

```bash
swift test
```

### 项目结构

```
Sources/
  ClipCore/        历史存储、剪贴板监听、插件接口(不含界面和具体插件)
  MarkdownPlugin/  Markdown 转富文本插件,只依赖 ClipCore
  ClipDown/        应用外壳:面板、菜单栏、设置、全局快捷键
Tests/             单元测试
scripts/           打包脚本
```

### 插件

功能以插件形式接入。Markdown 转换就是一个独立的模块,只依赖 `ClipCore` 里的插件接口。
应用外壳里只有一行注册代码(`state.plugins.register(MarkdownPlugin())`),
删掉它,这个功能就整体移除,不影响其他部分。

## 常见问题

**按 `⌘D` 没反应?**
可能和其他应用的全局快捷键冲突。到设置里换一个呼出键。

**选了记录但没有粘贴出来?**
检查“系统设置 → 隐私与安全性 → 辅助功能”里 ClipDown 是否已打开;
更新过应用后如果失效,删掉再重新添加。

**`⌘⇧V` 粘贴出来还是 Markdown 符号?**
目标应用可能不支持富文本。可以先在“备忘录”“Pages”“Word”等支持富文本的应用里试一下。

**换电脑 / 重装后想保留历史?**
把 `~/Library/Application Support/ClipDown/` 整个文件夹拷过去即可。
